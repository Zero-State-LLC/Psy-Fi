Privacy policy

PsyFi is a research and visualization instrument at psy-fi.space. This page says what the site does with data, as its code works today.

Effective date: 2026-11-08

Who runs PsyFi?
Zero State LLC operates psy-fi.space. The Zero State LLC privacy policy is the parent policy for this site.
Do I need an account?
No. There is no sign-up and no login, and PsyFi's own code sets no cookies. Cloudflare may set cookies it uses to deliver and protect the site; see Cloudflare cookies.
What does my browser send to the server?
The settings you run: grid size, steps, seed and preset for a simulation; substance, recipe, mode, intensity, seed and modulator levels for the Live Experience; and any planner notes or time and place anchors you type in. Export journey also sends stills of the rendered field. If you turn on the camera, microphone, motion, MIDI, gamepad or ambient light inputs, they are read in your browser and only a level between 0 and 1 is sent, never the picture or the sound.
What happens to an image I upload?
Image seed and Read image send the file to the PsyFi server, which works on it in memory and does not save it. Image seed sends it as soon as you choose it, to suggest a formula. After Condition & load, opening the GPU Lab sends a 256-pixel processed copy of the image back to the server to build its scene. Read image also sends a copy, resized to at most 384 pixels on its longest side, to NVIDIA's hosted model API (integrate.api.nvidia.com) to get a caption (NVIDIA privacy policy). The caption is inferred and is not medical advice.
What does the server keep?
Simulation jobs are held in the server's memory, at most 64 at a time, and are gone when the server restarts or sleeps after 10 minutes without traffic. There is no database of visitors. The server prints a standard access line for each request it handles (the connecting address it sees, the request and the response status) to its console, and Cloudflare can keep those console lines in its logs for up to seven days. Diagnostic telemetry is off on this site, so the opt-in box only sends your choice and records no events.
What stays in my browser?
Run history, saved comparisons and journeys live in this browser's IndexedDB (psyfi-sessions). The last session is in local storage (psyfi.session.v1.last). Session storage holds your field resolution (psyfi.resolution.v1), the launch scan note (psyfi.launch.v1.completed), a dismissed-recovery flag (psyfi.session.v1.recovery_dismissed) and the image seed handed to the GPU Lab, with its processed copy of your image (psyfi.imageSeed.v1). A service worker caches the site's files so it opens offline. Clear History, Clear comparisons and Clear journeys remove those saved records; clearing site data in your browser removes all of it.
Who hosts and measures the site?
Cloudflare hosts psy-fi.space and runs the PsyFi server, so every request passes through Cloudflare's network (Cloudflare privacy policy). Cloudflare Web Analytics is on: Cloudflare adds a script from static.cloudflareinsights.com to each page, and the script reports the page address, the referring page, and load and responsiveness timings to Cloudflare through this site's own /cdn-cgi/rum address. Cloudflare says it uses no cookies and stores nothing in your browser. PsyFi adds no other analytics or advertising, and its fonts are served from this site. The API Docs pages (/docs and /redoc), which FastAPI generates, are the exception: they load their viewer from cdn.jsdelivr.net and an icon from fastapi.tiangolo.com, and /redoc also loads fonts from Google Fonts.
Is this medical advice?
No. PsyFi models phenomenology for research and visualization only. Nothing on the site, an image caption included, is medical, diagnostic or therapeutic advice.
